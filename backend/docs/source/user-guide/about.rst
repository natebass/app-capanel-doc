About the California Accountability Panel
=========================================

The California Accountability Panel is an open-source dashboard for exploring
key school performance metrics in California.

The project uses public data from the California Department of Education to
make education performance information easier to understand and explore.

The application is intended for guardians, schools, and educational policy
makers who want real-time, personalized performance data.
