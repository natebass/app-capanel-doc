Achievement Levels
================================================================

Each test reports achievement on its own scale, with its own number of levels
and its own wording.  This application stores every distribution in four generic
level slots and keeps the vocabulary in a *level scheme* attached to the test
and year, so the level names always travel with the numbers.

Levels are always stored lowest first: level 1 is the weakest performance on
every test, whichever order the research file prints them in.

Where the state publishes a combined "met or above" figure — Smarter Balanced
and CAST do — it is stored as published.  Where it does not, the application
sums the levels at or above the state's proficiency cut and marks the value as
derived, so a report can be explicit about which it is showing.
